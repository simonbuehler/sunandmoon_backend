# Changelog

## 1.0.0 (2026-01-20)

Initial release of the Sun and Moon Datasource Backend Plugin for Grafana.

### Features
- Backend datasource plugin supporting public dashboards
- Sun metrics: altitude, azimuth, distance, solar noon, sunrise, sunset, dawn, dusk, golden hour
- Moon metrics: altitude, azimuth, distance, illumination, phase, moonrise, moonset
- Configurable location (latitude/longitude)
- Compatible with Grafana 11.0.0 and above
